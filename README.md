# موقع BESTRAK — النموذج رقم ٢

صفحة إعلانية عربية بالكامل، اتجاهها من اليمين إلى اليسار، تعرض **اثنتي عشرة ميزة مبنيّة** في منصة رتل للنقل واللوجستيات — كل ميزة معروضة وهي تعمل، لا موصوفة بنصّ.

**الوعد:** مالك محجوز حتى تصل بضاعتك.

---

## الفتح

الصفحة **ملف واحد مكتفٍ بذاته**. تفتحها بطريقتين:

```bash
# ١) مباشرةً — بلا أي تشغيل
افتح index.html بالمتصفّح

# ٢) عبر خادم محلّي
node server.js          # ثم http://localhost:5180
set PORT=8080 && node server.js   # لتغيير المنفذ
```

**المتطلّب الوحيد للخيار الثاني:** `Node.js`. ولا حزم خارجية إطلاقاً — لا `npm install`.

## ما في الصفحة

| القسم | المحتوى |
|---|---|
| **البطل** | خريطة سوريا والعراق بحدودهما الفعلية، ومعبراهما، وشاحنات تعبر بينهما |
| **أرقام** | ١٥ محافظة · ١٢ مرحلة رحلة · ٥ مرشّحين لكل موجة · ٤٨ ساعة اعتراض |
| **همومك** | ست مخاوف بصيغة السوق العامية، وجواب كل واحدة من ميزة مبنيّة |
| **الميزات ١٢** | ثلاث كتل: الثقة والمال · التشغيل · الإدارة والشفافية |
| **بصراحة** | ثلاث ميزات **لم تُبنَ بعد**، مكتوبة صراحةً |

### الميزات الاثنتا عشرة

**الثقة والمال** — الحلقة المالية المغلقة · فصل الرؤية المالية · النقد الموثّق بإيصال · سجل التدقيق والدفاتر غير القابلة للتعديل

**التشغيل** — المطابقة بموجات والقبول الذرّي · حاسبة السعر وعدد المركبات · الطلب متعدد المركبات · اثنتا عشرة مرحلة والقفل الجغرافي

**الإدارة والشفافية** — الأهلية بطبقتين · ملف المركبة ٣٦٠ · غرفة العمليات · شاشة «أرباحي»

---

## قواعد البناء

- **بلا مكتبات** — لا `React` ولا مكتبة رسوم ولا حزمة واحدة. `HTML` و`CSS` و`SVG` خالص.
- **بلا طلبات شبكة** — عدا خطّي `Cairo` و`Tajawal` من Google Fonts. الشعار مضمّن كـ`data URI`، والرسوم كلها `SVG` داخل الصفحة.
- **عربي و RTL أصيل** — خصائص منطقية (`margin-inline-start`) لا يمين/يسار.
- **الهاتف أولاً** — بلا تمرير أفقي.
- **`prefers-reduced-motion`** — من يعطّل الحركة يرى لقطة نهائية معبّرة لكل مشهد، لا شاشة فارغة.
- **`IntersectionObserver`** — الرسم يتوقّف خارج الشاشة فلا يستهلك بطارية الزائر.

### الشاحنات المتحرّكة

تسير بـ`offset-path` مع `offset-distance` من ٠٪ إلى ١٠٠٪، و`offset-rotate: 0deg` يبقيها قائمة فلا تنقلب مع انحناء الطريق. وعند تعطيل الحركة تقف عند ٥٥٪ من مسارها.

### الخريطة

إحداثيات حدود سوريا والعراق **حقيقية**، مُسقَطة بإسقاط متساوي المستطيلات مع تصحيح `cos(33.5°)`. المضلّعان يتطابقان على الحدّ المشترك بالنقطة — فالحدّ السوري-العراقي يظهر دون أن يُرسم. والمعبران (**البوكمال–القائم** و**اليعربية–ربيعة**) في موضعيهما الفعليين.

> لا تُرسم ممرات **داخل** العراق. رتل منصة سوريّة تدعم التصدير والاستيراد والترانزيت عبر معابرها، فالعراق وجهة عبر الحدود لا سوق داخلي.

## نظام التصميم

| الدور | اللون |
|---|---|
| الهوية | كحلي ليلي `#0b1f33` |
| محمّل / ربح | أخضر زمردي `#06be7e` |
| اللكنة | كهرماني `#ff9f1a` |
| ثانوي | أزرق سماوي `#2e9be6` |
| فارغ / معطّل | رمادي `#93a3b1` |

**الخطوط:** `Cairo` للعناوين · `Tajawal` للمتن. كل الرموز في أول كتلة `<style>` — تغييرها هناك يغيّر الصفحة كلها.

---

## قاعدة المحتوى

**لا تُعلَن ميزة غير مبنيّة.** قسم «بصراحة» في آخر الصفحة يذكر صراحةً ما لم يُنجَز بعد: التتبّع الحيّ · أحمال العودة · الدفع الإلكتروني. الشاحنات والأشخاص في الرسوم **زينة بصرية لا ادّعاء وظيفي**.
